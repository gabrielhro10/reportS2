# ReportS2

Recibe varios PDF de una vez, los agrupa por cuota y genera un PDF listo para subir a SECOP II por cada una (detecta cada sección por su texto y las ordena). Entrega los datos del reporte en un bloque de texto y permite marcar cada cuota como reportada. Todo se procesa en el dispositivo.

## Instalar como app (PWA)

| Dispositivo | Pasos |
| --- | --- |
| iPhone / iPad | Safari → Compartir → Añadir a pantalla de inicio |
| Mac (Safari 17+) | Archivo → Añadir al Dock |
| Chrome / Edge | Icono de instalar en la barra de direcciones |
